# Deployed Smart Contracts (Local Ganache)

## ElectionFact.sol (Factory)

*Note: You must compile and deploy this contract using Node.js v11.14.0. Node.js v22 throws a `Maximum call stack size exceeded` error with `solc@0.4.25`.*

**When you successfully run `node Ethereum/deploy.js`:**
1. Copy the deployed contract address from the console output.
2. Update the hardcoded address in `Ethereum/election_factory.js`:
   ```javascript
   const instance = new web3.eth.Contract(
       JSON.parse(ElectionFactory.interface),
       'YOUR_NEW_DEPLOYED_ADDRESS_HERE' // <--- UPDATE THIS
   );
   ```
3. Paste the deployment details here:

- **Contract Address:** `0xCfEB869F69431e42cdB54A4F4f105C19C080A601`
- **Network:** Ganache local (port 8545, networkId 5777)
- **Deployer Account:** `0x90F8bf6A479f320ead074411a4B0e7944Ea8c9C1` (Account 0)

## ABI Location
- **File:** `Ethereum/Build/ElectionFact.json` and `Ethereum/Build/Election.json`
